================================================================================
TROUBLESHOOTING
================================================================================

CORS Error in Console:
  Error: "Access to XMLHttpRequest has been blocked by CORS policy"
  Solution: Verify backend running, check allow_origins matches your URL

Cannot Connect:
  Error: "Failed to fetch" or connection refused
  Solution: Verify backend running (curl http://localhost:8000/health)

Results Not Displaying:
  Error: Results don't show after clicking Analyze
  Solution: Check Network tab for 200 status, check console for JS errors

Port Already in Use:
  Error: "Address already in use"
  Solution: Stop the service on that port, or use different port number

See documentation for more troubleshooting:
  → CORS_CONFIGURATION.md (Troubleshooting section)
